In the Berlandian school of witchcraft and wizardry, Wartshog, each year newcomer students are distributed between three houses: Andorgryff, Bufflehuff, and Clawenrave. The distribution is done by a hat, called the Distributing Hat. The students put on the hat one by one (in a certain fixed order), and the hat shouts out loud the name of the house to which the student will belong. This year, there are AAA, BBB, and CCC places in the three houses respectively, and the number of new students is A+B+CA + B + CA+B+C, so there will be exactly AAA new students in Andorgryff, BBB in Bufflehuff, and CCC in Clawenrave. The Distributing Hat follows one additional rule: no two consecutive students will be put in the same house.

Can you tell how many different ways exist for distributing the students between the houses? Since this number might be very big, you need to give the answer modulo 109+710^9 + 7109+7. Two distributions are considered different if at least one student is assigned to a different house.

Input data

The first line contains TTT, the number of test cases. Each of the following TTT lines contains three integer numbers AAA, BBB and CCC.

Output data

For each test case, output a single number on a separate line, the number of different ways to distribute the students, modulo 109+710^9 + 7109+7.

Constraints and Clarifications

  • 1≤T≤201 \le T \le 201≤T≤20;
  • 0≤A,B,C≤100 0000 \le A, B, C \le 100 \ 0000≤A,B,C≤100 000;
  • A+B+C≥1A + B + C \ge 1A+B+C≥1;
  • The modulo operation (a mod m)(a \bmod m)(amodm) can be written in C/C++/Python as (a % m). To avoid the integer overflow error, remember to reduce all partial results through the modulus, and not just the final result!
  • Notice that if x<109+7x < 10^9 + 7x<109+7, then 2x2 x2x fits into a C/C++ int.

Explanation

In the first sample case, there is only one possible distribution: BABAB (here we write the initial letter of the chosen house for each student in order).

In the second sample case, the 12 possible ways are: ABABC, ABACB, ABCAB, ABCBA, ACBAB, BABAC, BABCA, BACAB, BACBA, BCABA, CABAB, CBABA.

In the third sample case, there will be at least two consecutive A-s in any distribution, so the hat has no way to distribute the students.
