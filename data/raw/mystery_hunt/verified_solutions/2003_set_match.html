M Puzzle: Set Match

by Francis Heaney and Lance Nathan

Each set of lines contains two clues with their letters scrambled vertically and rotated horizontally. Those clues indicate two members of a set (as clued by "one bourbon, one scotch [and one beer]" and "paper, scissors [and rock]").

The clues are ordered by rotation: the ones that start in the first column come first, the ones that start in the second column come second, and so forth. Additionally, one pair of columns has been switched in each clue; taking the letters found in those positions in the third member of the set for each pair of clues gives a final clue pair.
